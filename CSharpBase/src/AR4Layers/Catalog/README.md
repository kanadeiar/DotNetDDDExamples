# Inventory.

Пример универсального поддомена каталога товаров

## Описание

Образец универсального поддомена, который имеет сложные структуры данных.

## Назначение

Хранение в каталоге информации о всех товаров магазина, которые доступны для покупки.

## Сценарии

- Просмотр всего каталога товаров

- Фильтрация товаров

- Редактирование названия любого товара

- Редактирование цены любого товара

- Удаление любого товара на складе

## Инструменты

1) Предметное проектирование.

2) Активная запись.

3) Слоеная архитектура (4 слоя).

4) Ромб тестирования.
