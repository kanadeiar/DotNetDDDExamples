# Inventory.

Пример важного основного поддомена каталога товаров

## Описание

Образец основого поддомена, содержащий в себе важную бизнес-логику.

## Назначение

Хранение в каталоге информации о всех товаров магазина, которые доступны для покупки.

## Сценарии

- Просмотр всего каталога товаров

- Фильтрация товаров

- Редактирование названия любого товара

- Редактирование цены любого товара

- Удаление любого товара из каталога товаров
 
## Инструменты

1) Предметное проектирование.

2) Модель предметной области, основанная на событиях.

3) CQRS.

4) Пирамида тестирования.

5) Простейший диспетчер событий.
