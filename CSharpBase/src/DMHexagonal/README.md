# Domain Model Hexagonal

Пример ограниченного контекста

## Описание

Пример основного простого ограниченного контекта предметного проектирования.

## Содержимое

Пример основного поддомена инвентаризационной базы

Образцовое консольное приложение

## Глоссарий

Бренд - Brand - бренд товаров

Категория - Category - категория товаров

Товар - Product - товар каталога товаров, доступный для покупки

Фильтр - Filter - фильтрация товаров с целью более быстрого поиска нужного

Переименовать - Rename - изменить название товара

Цена - Price - цена товара в каталоге товаров

Консоль - Console - консольный интерфейс взаимодействия с пользователем.

## Инструменты

1) Предметное проектирование.

2) Модель предметной области.

3) Гексагональная архитектура.

4) Пирамида тестирования.
