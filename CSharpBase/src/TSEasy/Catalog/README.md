# Inventory.

Пример простейшего вспомогательного поддомена каталога товаров

## Описание

Образец простейшего вспомогательного поддомена, который не имеет сложных структур данных.

## Назначение

Хранение в каталоге информации о всех товаров магазина, которые доступны для покупки.

## Сценарии

- Просмотр всего каталога товаров

- Фильтрация товаров

- Редактирование названия любого товара

- Редактирование цены любого товара

- Удаление любого товара на складе

## Инструменты

1) Предметное проектирование.

2) Транзакционный сценарий.

3) Простейшая архитектура.

4) Перевернутая пирамида тестирования.
